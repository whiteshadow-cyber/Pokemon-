# Pokémon App

A simple React app (Vite) that fetches Pokémon from the free [PokéAPI](https://pokeapi.co/).

## Features
- Fetches data from a public API
- Shows Pokémon as cards (React components)
- Loading and error messages
- Search box + "favorites only" filter
- Favorites saved in localStorage

## How to run
```
npm install
npm run dev
```
